# Reporting Inaccuracies

This project was fully generated by AI and may contain astronomical inaccuracies. We welcome corrections to improve the accuracy of celestial body data.

## 🎯 Common Areas of Inaccuracy

### Celestial Body Properties
- **Relative sizes**: May not be precisely to scale
- **Orbital distances**: Scaled for visualization, not scientific accuracy
- **Orbital speeds**: Approximate, may not match real values
- **Orbital periods**: May be rounded or approximate

### Scientific Facts
- **Descriptions**: May contain oversimplifications or errors
- **Discovery information**: Names, dates, or discoverers may be wrong
- **Physical characteristics**: Temperatures, diameters may be inaccurate
- **Unique features**: May miss important details or contain errors

### Data Sources
Information was sourced from general knowledge and may not reflect:
- Latest scientific measurements
- Most accurate orbital parameters
- Recent discoveries or reclassifications
- Precise physical constants

### Visualization scale (intentional, but worth knowing)

- **Sizes are compressed.** The Sun is drawn at radius 6 against Earth's 1 (real ratio ≈ 109).
  Gas giants are shown at roughly 35-65 % of their true size relative to Earth (Jupiter 4 vs ≈ 11,
  Saturn 3.5 vs ≈ 9.1, Uranus 2.5 vs ≈ 4.0, Neptune 2.4 vs ≈ 3.9). Terrestrial planets are close to
  true relative size.
- **Distances are compressed** non-linearly (Neptune is about 5.6× Earth's distance here, ≈ 30× in
  reality), and orbits are circular except Pluto's.
- **Orbital speeds are relative**, not physical. Moons are much slower relative to their planets
  than in reality (the Moon moves at 2× Earth's rate here versus ≈ 13 orbits per Earth year), chosen
  for readability.

## 📝 How to Report

### Creating an Issue

1. **Check existing issues** first to avoid duplicates
2. **Use the template** below for your report
3. **Provide sources** when possible (NASA, ESA, IAU, peer-reviewed papers)
4. **Be specific** about what's wrong and what's correct

### Issue Template

```markdown
**Type of Inaccuracy**: [Orbital Data / Physical Properties / Scientific Fact / Description / Other]

**Object Affected**: [Planet/Moon/Satellite Name]

**Current (Incorrect) Value**:
[Current value in the code]

**Correct Value**:
[The accurate value with source]

**Source(s)**:
[NASA, ESA, IAU, scientific paper, etc.]

**Additional Context**:
[Any additional details that would help fix this]
```

## 🔧 How to Fix Directly (for Contributors)

### Step 1: Locate the Data File

- **Planets**: `src/data/planets.ts`
- **Moons**: `src/data/moons.ts`
- **Satellites**: `src/data/satellites.ts`

### Step 2: Update the Data

Find the object's data block and update the incorrect field:

```typescript
// Example: Fixing Earth's temperature
{
  id: 'earth',
  name: 'Earth',
  // ... other properties
  temperature: '-88°C to 58°C',  // UPDATE THIS
  // ... other properties
}
```

### Step 3: Submit a Pull Request

1. Create a new branch: `git checkout -b fix/earth-temperature`
2. Make your changes
3. Commit: `git commit -m "Fix Earth temperature range"`
4. Push: `git push origin fix/earth-temperature`
5. Open PR with reference to the issue
